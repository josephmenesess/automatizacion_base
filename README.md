# Automatizacion Base

Proyecto inicial para experimentos y desarrollo de automatización usando Python y Git.

## Objetivo

Construir una base organizada para desarrollar scripts, pruebas y herramientas relacionadas con automatización.

## Estructura inicial

* `docs/` → documentación y notas
* `notebooks/` → pruebas y experimentos
* `src/` → código reusable del proyecto

## Estado actual

Repositorio inicial configurado con Git.
